# Agent Operating Guidelines & Rules

## Mandatory Project Status & Sync Policy

1. **Always Maintain Project Status**:
   - `PROJECT_STATUS.md` at the repository root is mandatory.
   - It serves as the single source of truth for all milestone progress, component matrices, and verification logs.

2. **Update After Every Process**:
   - After completing each task, feature, refinement, or process, immediately update `PROJECT_STATUS.md` with:
     - The updated milestone status.
     - Any new component or verification details.
     - A concise chronological summary in the Process Execution & Verification Log.

3. **Mandatory GitHub Push**:
   - Every completed process must be committed and pushed to `origin/main` on `https://github.com/prakashjune8/test-agent-skills`.
