# Test Agent Skills

Repository containing Antigravity agent skills and runbooks for software development.

## Included Skills

### [Full-Stack Development](.agents/skills/fullstack-development/SKILL.md)
Comprehensive workflow and coding standards for modern full-stack TypeScript/JavaScript applications.

- **Frontend UI Architecture**: Design system tokens, atomic component hierarchy, WCAG AA accessibility, responsive design, and state management.
- **Backend Architecture & Security**: Layered Controller-Service-Repository pattern, centralized error handling, Zod validation, and production security hardening.
- **API Contracts & Type Safety**: Shared Zod DTOs, uniform response envelopes, and TanStack Query data synchronization.
